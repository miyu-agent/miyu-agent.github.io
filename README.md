# Miyu website

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository holds the source of the Miyu website, which is at <https://miyu-agent.github.io/>.

The website is a static single page, and you can preview it by opening `index.html` directly.

## Directory layout

The table below describes what each file and directory in the repository is for:

| Path | Description |
|---|---|
| `index.html` | The assembled page, generated by `src/build.py`; do not edit it by hand |
| `assets/` | Screenshots of the interfaces (`.webp`), a screen recording of the terminal integration (`shell.mp4`, `shell-poster.jpg`), and the logo in various sizes (`assets/logo/`) |
| `src/template.html` | The source of the page |
| `src/build.py` | Fills the ASCII art bitmap into the template and generates `index.html` |
| `src/mask.b64`, `src/make_mask.sh` | The 220×220 bitmap used by the ASCII art on the home page, and the script that regenerates the bitmap from `src/logo.png` (needs ImageMagick and Pillow) |
| `src/logo-v2-source.png`, `src/key_logo.py` | The original logo image, and the script that removes its background (needs NumPy and Pillow) |

## Build

After you change `src/template.html`, run the following command to regenerate `index.html`:

```sh
python3 src/build.py
```
